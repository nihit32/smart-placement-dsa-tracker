# Smart Placement & DSA Tracker

A full-stack platform for students to manage
DSA preparation, placement applications,
interview preparation and career progress.

## Tech Stack

- Java
- Spring Boot
- MySQL
- Spring Security
- JWT
- React
- Tailwind CSS

## Features

- Student Authentication
- Student Profile
- DSA Progress Tracking
- Placement Application Tracking
- Interview Preparation
- Progress Dashboard
